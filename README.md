# 🐙 Scylla OSINT Framework
A multi-dimensional, full-screen terminal OSINT tool.

## Features Added
- **WAF Detection:** Identifies Cloudflare, AWS WAF, etc.
- **Password Profiler:** Analyzes breached password TXTs to generate mutation wordlists.
- **Automated Reporting:** Exports findings to JSON, CSV, or PDF categorized by CVSS.
- **Rate-Limit Engine:** Built-in proxy rotation and request throttling.

## Installation
1. Unzip the archive.
2. `pip install -r requirements.txt`
3. `python main.py`
